# Объединённое задание для 2, 3, 4 и 5 лабы
Необходимо собрать легковесный образ опенсорсного приложения из исходного кода с помощью нескольких уровней зависимостей. Далее нужно запустить полноценное веб-приложение из разных репозиториев.

1. Образы должны быть легковесными
2. Использовать базовые легковесные образы - alpine
3. Статика (зависимости) должна быть внешним томом `volume`
4. Контейнеры должны запускаться от непривилегированного пользователя
5. После установки всех нужных утилит, должен очищаться кеш
6. Для бэкенда создать Dockerfile, который будет называться system. В него будут установлены все зависимости для сборки проекта. Как пример голая node нужной версии.
7. Для бэкенда создать Dockerfile Для сборки и назвать его build. В нем будет собираться проект, он должен использовать имедж system. В build нельзя устанавливать никакие дополнительные зависимости, т.е. apk add, apt install и пр. запрещены. В нём можно только скачивать зависимости и делать сборку проекта.
8. Для бэкенда создать Dockerfile, который будет запускать код , который собрался в build. В нем должен быть только инструмент для запуска вашего проекта, как пример для node проекта - npm run start и пр. Если у вас python проект - объединять 2 и 3 шаги - можно. Если вы билдите проект на GO - тогда должен быть только бинарник для запуска.
9.  При старте бэкенда должно быть учтено выполнение автоматических миграций
10. Запустить сервисы `backend`, `frontend`, `db` и `nginx-proxy` в `docker-compose.yml`
11. Вся конфигурация выполняется через переменные окружения, передающиеся через `env_file` и `environment`
12. Точкой входа является только `nginx-proxy`, остальные сервисы не имеют открытых наружу портов
13. Должна быть возможность конфигурирования через файлы настроек в виде `volume`
# Использованное приложение
Panpipe - https://github.com/Panpipe-team
# How to start
1. Download https://github.com/Panpipe-team/panpipe-backend to `backend`
2. Download https://github.com/Panpipe-team/panpipe-frontend to `frontend`
3. `docker compose up -d`
4. Navigate to `http://localhost:8080`
